# Security and data handling

This repository contains narrative case studies only.

Do not add:

- Employer or client datasets
- Applicant, customer, contact, or employee identifiers
- Individual performance records
- Internal financial assumptions or management reports
- Unapproved company logos or proprietary templates
- API keys, authentication tokens, local workstation paths, or logs
- Screenshots that expose names, identifiers, browser tabs, or source paths

Any future demonstration dataset must be created from scratch, use fictional entities, and be checked for accidental similarity to the original records. A private repository is not a substitute for proper data minimisation.
